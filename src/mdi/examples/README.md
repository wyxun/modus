# MDI examples：芯片层调用示例

`application.c` 使用 `mdi/instance.h` 中的资源 token，演示应用如何调用 MDI。它不是
新的芯片后端，也不负责初始化时钟、GPIO、DMA 或故障输入；这些内容属于
`peripheral/<chip>/mdi/`。

示例的使用顺序是：

1. 芯片启动代码完成外设初始化和资源所有权配置。
2. 应用包含 `mdi/mdi.h` 以及一个芯片实例头文件。
3. 对于 ADC/PWM，在所属中断或明确的实时上下文中使用完成帧和提交接口。
4. 对于 I2C/SPI，在前台任务中执行有界事务，并由上层保证同一总线不被并发占用。

编译示例时必须把芯片实例的 include 路径加入编译器；公共 MDI 源码本身不依赖某个
具体芯片。
